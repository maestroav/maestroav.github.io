  1. Create the Slack app

    Paste one manifest, install it, and pick a channel.

  2. Deploy the Worker

    One command to Cloudflare Workers Free. Signatures are verified on every request.

  3. Add the org webhook

    GitHub sends a ping and “connected” appears in Slack.

Questions

Does it cost anything?

No. GitHub org webhooks, the Cloudflare Workers Free plan and a Slack app are all free at this volume.

Can it see my code?

No. It receives webhook metadata (titles, names, links) and never clones or reads repository contents.

Is the webhook secure?

Every request is checked against an HMAC signature before anything is posted.
